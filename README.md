# WhatsApp-cpp-system
WhatsApp-like Messaging System in C++ (OOP Training Project)
Software Engineering Training Project - Team 5

- **Jana Mohamed (Team Leader):** Main Menu, System Integration, Task Coordination & Overall Testing
- **Mohamed Yasser:** User Class, Password Validation & User Information Management
- **Kandy Hany:** Message Class, Message Display & Emoji Replacer
- **Seif Eldeen Ahmed:** Base Chat Class, Adding/Deleting Messages & Message Search
- **Nour Raef:** PrivateChat Class & Typing Indicator
- **Mohamed Mostafa:** GroupChat Class, Admin Management & Participant Permissions
- **Mohamed Emad:** WhatsApp Class, Authentication, User Management & Chat Management

## Requirements
- C++11 compiler or later.
- Compilation command: `g++ -std=c++11 -Wall -Wextra`
- Memory leak-free execution.
- Proper memory management for dynamically allocated Chat objects.
- Follow Object-Oriented Programming principles, including Inheritance and Polymorphism.
